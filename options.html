Messages Control settings

Save or Test asks Chrome to allow access to this endpoint's host. Message text and enabled pictures are sent there for classification. Use HTTPS for remote services.

This is a name heuristic, not an address-book lookup. Names containing digits or an email address are not protected by this setting.

Opening a thread marks it read: it loses its unread marker, and for RCS chats the sender gets a read receipt if you have those on (Messages settings → RCS chats → Send read receipts). Plain SMS/MMS sends no receipts. Turned off, picture threads are classified from their preview text only, which usually says just "Picture".

Archiving keeps the conversation (Messages → Archived) and brings it back when a new message arrives. Ages count from the latest message; for anything before today the list shows only the day, so it counts from the end of that day and never archives early. Archiving applies even in dry run; dry run prevents blocking and trashing.
